# Прототип записи на смены

## Запуск
Требуется Node.js 20+.

```bash
npm install
npm start
```

Открыть: http://localhost:3000

## Тестовые коды
1001 Иванов Иван
1002 Петров Пётр
1003 Сидорова Анна
1004 Кузнецов Максим
1005 Смирнова Ольга

## Что уже работает
- вход только по коду из списка сотрудников;
- просмотр доступных смен;
- ограничение количества мест;
- запись на смену;
- запрет повторной записи одного сотрудника на одну и ту же смену через UNIQUE(employee_id, shift_id);
- отмена записи;
- админ-панель со списком смен и бронирований;
- добавление новых смен;
- SQLite база данных.

Админ-панель в этом первом тесте открывается кнопкой без отдельного пароля — перед реальным запуском обязательно добавить авторизацию администратора.
